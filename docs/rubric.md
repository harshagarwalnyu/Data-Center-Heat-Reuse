# Judging rubric (official, received 2026-10-04)

5 categories x 4 points = 20 max. Scale: Excellent 4 / Good 3 / Satisfactory 2 / Needs Improvement 1.

| Category | What earns 4 | How Thermal Commons hits it |
|---|---|---|
| **Technology** | Cutting-edge or superbly applied; high complexity and sophistication | 8,760-hour dispatch on real TMYx weather, Carnot-bounded COP, storage SOC, CRF/LCOH; JSON contract model -> app; in-browser recompute on Explore sliders; map + Sankey. Show the machinery: "how it works" panel, tests passing, sources page. |
| **Presentation** | Clear, engaging, professional; communicates value AND workings | Story mode (11 steps, presenter notes, 5-min path), deck, video, printed one-pager + QR. Every step must say both *what it means* and *how we know*. |
| **Innovation / Creativity** | Novel approach, creative problem-solving, exceptional outcomes | Reframe: "the conditions under which Lansing could say yes" (binding CBA + Heat Supply Agreement, community co-op, public dashboard). "Right tool at every density" instead of one big pipe. Deep Green Lansing MI lesson. |
| **Execution** | Exceptionally well implemented, flawless functionality, polished finish | Zero console errors, no blank map, no wrong headline numbers, builds clean, works at 1366 and 1920, keyboard nav, >=18px text, deployed URL live. |
| **Theme** | Theme incorporated in a meaningful and integral way | Theme = waste heat -> community value. Every screen ties back to a Lansing household, farm, job, or ton of CO2; HDR 7-domain scorecard. |

## Rules for every lane
- Before shipping any change, ask: which rubric row does this raise, and does it risk Execution?
- Execution is the cheapest points to lose: a single broken step or wrong number costs more than a new feature earns.
- Presentation must show "workings", not only results: keep a visible methods/assumptions path from every headline number.
